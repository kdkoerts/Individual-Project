# Kevin's Individual Project

## Project set-up:
```
Need Java 25 installed.
Need Maven installed.
```


### Maven

```
cd backend
mvn clean install
cd ..
...
```

### Frontend

```
cd frontend
npm install

# Start the front-end server
npm run dev
# Check code for common mistakes and style conventions
npm run lint
# Create a production-worthy build of the client
npm run build
...
```

### Backend

```
cd backend
mvn spring-boot:run
...
```
Go to `http://localhost:8080/`


### things needed

```
npm install axios

```
